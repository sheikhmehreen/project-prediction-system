# NASA93 dataset

This project uses the NASA93 software-project dataset, a historical software cost-estimation dataset distributed through the PROMISE Software Engineering Repository.

- Dataset repository: https://promise.site.uottawa.ca/SERepository/datasets-page.html
- Dataset name: NASA93
- Observations in this project: 93

The dataset file is not stored in this folder by this structural setup. Obtain it from the PROMISE repository and place the project copy here when needed. Check the dataset's original terms and citation requirements before redistribution.

Do not commit private, modified, or otherwise restricted copies of the dataset without confirming that redistribution is permitted.
